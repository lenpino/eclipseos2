SWT Step 010. Tool bars

Objective

Implement the o.e.swt.widgets.ToolBar and ToolItem classes. The test case (SWT010_01) checks the item list, the layout, the selection and radio behavior, the events and the controls placed in separators automatically, and then shows several tool bars to be used by hand.

Task notes

The tool bar control of the eCS toolkit (etoolbar.h, er.toolbar.class) is not used: it can only append buttons, and it cannot remove or insert them nor report their bounds, which ToolItem.dispose(), ToolItem(parent, style, index), getBounds() and ToolBar.getItem(Point) need. The 2024 version of the toolkit has the same messages (it only adds the TBS_2D style). So each item is a Button (flat for a SWT.FLAT tool bar) that the ToolBar lays out in rows. See difference 012.
