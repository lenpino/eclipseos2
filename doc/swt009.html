SWT Step 009. Labels

Objective

Implement the o.e.swt.widgets.Label class. The test case should demonstrate all possible label variations.

Task notes

The Sash class (test case SWT009_12 and SWT009_13) is implemented on top of the splitter window class of the eCS toolkit. It behaves differently from the Windows one, see difference 011.

Step checklist

Operation Status Remarks
Add OS.TBInitialize(); OS.WC_ER_SPLITTER is the class name, not an atom Done [lpino] Sash calls it in its static initializer, before WinQueryClassInfo(). The class does not exist until then.
Mouse tracking in Sash (SWT.Selection with SWT.DRAG, final event on button release) Done [lpino] Verified by hand with both the vertical and the horizontal sash (the y axis is inverted to SWT coordinates).
Test case SWT009_13 Done [lpino] The automatic part cannot simulate the mouse. The splitter does not notify SBM_SETSPLITTERPOS, so the drag is checked only in the interactive part.
