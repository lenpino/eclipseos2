SWT Step 013. Directory dialog

Objective

Implement the o.e.swt.widgets.DirectoryDialog class. The test case SWT013_01 opens the dialog and, from a task that runs in its event loop, looks at its widgets and presses its buttons (31 automatic checks); then it shows a button that opens the dialog for being used by hand.

Task notes

There is nothing to wrap: WinFileDlg chooses files and the Workplace Shell has no common dialog for directories, so the dialog is built with SWT widgets, using the native Tree of step 011:

  • The roots are the drives (File.listRoots()). Every directory has a child with the text ... until it is expanded, so that the tree shows a plus sign without reading the disk (reading a floppy drive would stop the program). The Expand event replaces it with the subdirectories, sorted without regard to case.
  • The filter path is shown by expanding the directories that lead to it; if it is not there, the deepest one that exists is selected.
  • The dialog is an application modal shell with the manual layout that the other tests use. It is opened with an event loop of its own, like the dialogs of the other platforms do.

The differences with Windows are in difference 015.
