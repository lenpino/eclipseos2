Eclipse for OS/2 Transitional Project
=====================================

This repository contains the project on porting of the Eclipse SDK (www.eclipse.org)
to the OS/2 operating system. It's "transitional" because we hope that when we complete
the greater part of this work and get more or less functional OS/2 version we will join
the main stream of the Eclipse development, which is initially a cross-platform SDK.

For more info see the index.html in the /doc directory.
